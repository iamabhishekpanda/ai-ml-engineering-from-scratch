# Azure RAG Deployment

> Join storage, search, model access, security, and evaluation into one deployable retrieval system.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Learning Objectives

- Draw the ingestion and query paths separately.
- Preserve access filters from source to answer.
- Add groundedness and citation checks.
- Budget retrieval, model, and network latency.
- Deploy a rollback-safe RAG service.

## Practice

Use `code/main.py` to validate a RAG deployment plan. It checks ingestion, retrieval, generation, citation, and rollback stages.
