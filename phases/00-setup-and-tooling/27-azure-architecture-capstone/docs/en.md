# Azure AI Architecture Capstone

> Defend a complete AI solution design with deployment evidence, evaluation evidence, and an operating model.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Learning Objectives

- Produce context, container, data-flow, and deployment views.
- Explain Azure service and framework trade-offs.
- Demonstrate identity, security, evaluation, and rollback controls.
- Present cost, latency, reliability, and quality budgets.
- Write an architecture decision record for review.

## Practice

Use `code/main.py` to validate the capstone evidence checklist. The artifact does not contact Azure; it checks that the design is complete before deployment.
