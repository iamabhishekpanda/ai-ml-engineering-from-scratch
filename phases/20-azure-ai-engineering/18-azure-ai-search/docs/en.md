# Azure AI Search

> Build retrieval that is explainable, filterable, and measurable before connecting it to generation.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals, Data Management
**Time:** ~60 minutes

## Learning Objectives

- Choose fields for keyword, vector, and hybrid retrieval.
- Preserve source identifiers and chunk provenance.
- Apply tenant and security filters before ranking.
- Measure recall, ranking quality, and groundedness separately.
- Reject an answer when evidence is missing.

## Practice

Use `code/main.py` to validate an index contract. The contract requires a source id, content field, embedding field, and access filter.
