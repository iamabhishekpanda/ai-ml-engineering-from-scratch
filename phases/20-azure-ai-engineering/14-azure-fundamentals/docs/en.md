# Azure AI Engineering Fundamentals

> Map an AI workload to Azure services, deployment boundaries, and measurable constraints.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## Learning Objectives

- Separate model, data, application, and platform responsibilities.
- Choose Azure services from workload constraints.
- Define latency, reliability, privacy, and cost budgets.
- Write a small architecture decision record.
- Identify the evidence required before deployment.

## Practice

Use `code/main.py` to validate a service plan. Record the workload, trust boundary, data class, deployment target, and rollback signal before selecting a service.
