# Phase 20: Azure AI Engineering

> Deploy, secure, evaluate, and operate AI systems on Azure.

## Start this phase

**Prerequisites:** Phase 0 setup, math and machine learning foundations, retrieval, and agent engineering.

**First lesson:** [Azure AI Engineering Fundamentals](14-azure-fundamentals/)

This phase is a provider-focused extension to the first-principles curriculum. The artifacts run offline and do not require Azure credentials. Apply the plans to an Azure subscription only after identity, budget, security, and rollback controls are reviewed.
