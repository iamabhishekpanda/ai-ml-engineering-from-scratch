# تنفيذ وكيل Azure

> نشر وكلاء استخدام الأدوات مع حالة صريحة، والإذن، والموافقة، وقتا، وسبل الاسترداد.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Functions for AI Workloads, Azure Security and Secrets
**Time:** ~75 minutes

## أهداف التعلم

- تصميم العميل كآلة دولة مع الانتقالات المحدودة.
- تطبيق الإذنات الأداة لكل مهمة ومحيط المستخدم.
- إضافة أبواب الموافقة للعمل غير المعاد
- التعافي من التوقفات الزمنية، الأحداث المكررة، والفشل الجزئي في الأداة.
- تتبع كل قرار دون تخزين حمولات مفيدة حساسة

## التدريب

استخدام`code/main.py`كل حافة أداة تحتاج إلى إذن، وقتاً، وإعادة المحاولة، و سلوك التحقيق.
