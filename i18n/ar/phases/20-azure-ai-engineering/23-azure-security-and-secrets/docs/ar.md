# أمن و أسرار أزور

> حماية الهويات والإشارات والوثائق ومخرجات النموذج عبر حدود النظام الذكاء الاصطناعي الكامل.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## أهداف التعلم

- تصنيف حساسية الإرسال، الوثيقة، الإضافة، والخروج.
- تخزن الأسرار في خزنة المفتاح والوصول إليها من خلال الهوية المدارة.
- تطبيق أقل امتيازات على البيانات ومصادر النموذج.
- اختبار الحقن السريع، إزالة البيانات، واستخدام الأدوات غير الآمنة.
- تحديد أدلة التحقيق والدورة.

## التدريب

استخدام`code/main.py`لتصديق خطة أمنية، وهي ترفض أسرار النص الصريح وملكية مفقودة لمسارات البيانات الحساسة.
