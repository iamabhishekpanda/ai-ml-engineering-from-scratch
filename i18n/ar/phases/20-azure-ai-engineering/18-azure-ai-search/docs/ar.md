# البحث عن الذكاء الاصطناعي في Azure

> قم ببناء عملية استرداد يمكن شرحها، والتحذير، والقياس قبل ربطها بالإنتاج.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals, Data Management
**Time:** ~60 minutes

## أهداف التعلم

- اختر الحقول للكلمة الرئيسية والمتجهة والحصول على الهجين.
- الحفاظ على مُعارف المصدر ومصدر الجزء
- تطبيق مستأجر ومرشحات الأمن قبل التصنيف.
- قياس الاحتفاظ بالذكرى، الجودة في التصنيف، والقاعدة بشكل منفصل.
- رفض الإجابة عندما تفتقر الأدلة

## التدريب

استخدام`code/main.py`للتحقق من اعتماد عقد مؤشر. يتطلب العقد معرف المصدر، وحقل المحتوى، وحقل التضمين، وصفّر الوصول.
