# عقود تخزين البيانات و Azure

> حافظ على المستندات والبيانات المعدنية والإدمج وقواعد دورة الحياة متوافقة على طول مستوى بيانات الذكاء الاصطناعي.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## أهداف التعلم

- تصنيف البيانات المصدرة قبل تخزينها أو إدراجها.
- تعريف البقع، البيانات المعدنية، وعقود الحذف.
- تصميم تناول غير قوي و سلوك التكرار
- فصل البيانات الخامة والمعالجة والقيام بتقييمها.
- التحقق من دليل الاحتفاظ والحذف.

## التدريب

استخدام`code/main.py`للتحقق من عقد التخزين. فإنه يفتقد البيانات المعدنية المطلوبة، والاحتفاظ، وإعادة تشغيل الحقول دون الحاجة إلى حساب أزور.
