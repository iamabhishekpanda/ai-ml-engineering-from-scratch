# وظائف Azure لتحملات عمل AI

> استخدم وظائف القائمة على الأحداث للمهام المحددة، محفزات تناول الطعام، وتنسيق خفيف الوزن.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Container Apps, APIs & Keys
**Time:** ~60 minutes

## أهداف التعلم

- اختر وظائف للعمل المحدد، القائم على الأحداث.
- تعريف الزناد، محاولة ثانية، وقت وقف، والرسائل السامة سلوك.
- أبقوا المديرين غير قادرين و قابلين للملاحظة
- تجنب وضع وظائف نموذجية طويلة في مسار الطلب القصير.
- تصميم عملية استمرارية للموظف

## التدريب

استخدام`code/main.py`لتؤكيد خطة تشغيل الوظيفة. فإنه يُحقق من الإستغناء، وقتاً متأخرًا، ومحاولة إعادة، وقرارات غير مكتوبة.
