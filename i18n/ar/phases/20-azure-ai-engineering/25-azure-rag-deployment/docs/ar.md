# تنفيذ Azure RAG

> انضم التخزين والبحث والوصول إلى النموذج والأمن والتقييم إلى نظام واحد قابل للتنفيذ.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## أهداف التعلم

- رسم مسارات الإبتلاع والسؤال بشكل منفصل.
- الحفاظ على مرشحات الوصول من المصدر إلى الإجابة.
- إضافة التحقق من التأريخ والإستشهاد
- استرداد الميزانية، النموذج، وتأخير الشبكة.
- قم بتنفيذ خدمة "RAG" آمنة من التدفق

## التدريب

استخدام`code/main.py`لتصديق خطة نشر RAG. فإنه يراقب مراحل استهلاك، استرداد، توليد، الاستشهاد، والعودة.
