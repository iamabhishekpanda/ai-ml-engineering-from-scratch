# أساسيات هندسة أزور AI

> خريطة حمولة عمل الذكاء الاصطناعي إلى خدمات Azure وحدود التنفيذ والقيود القياسية.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## أهداف التعلم

- مسؤوليات نموذجية ومدنية بيانات وتطبيقات و منصة منفصلة.
- اختر خدمات Azure من قيود الحمل المنزلي
- حدد التأخير والموثوقية والخصوصية وميزانيات التكلفة.
- اكتب سجلًا صغيرًا لتقرير الهندسة المعمارية.
- تحديد الأدلة المطلوبة قبل الانطلاق.

## التدريب

استخدام`code/main.py`لتؤكيد خطة الخدمة. سجل الحمل المطلوب، حدود الثقة، فئة البيانات، هدف التنفيذ، وإشارة الانسحاب قبل اختيار خدمة.
