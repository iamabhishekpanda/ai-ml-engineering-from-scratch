# Azure OpenAI

> تصميم النموذج الوصول حول أسماء النشر والحصص والإجراءات الإعادة والسلامة والدليل على التقييم.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## أهداف التعلم

- فصل موارد Azure OpenAI عن أسماء النموذج للتنفيذ.
- إشارات الميزانية، التأخير، التكامل، والفشل الإعادة في المحاولات.
- تأكيد الناتج المهيكلي قبل أن يصل إلى رمز التطبيق.
- إضافة سلامة المحتوى ومعالجة الرفض إلى حدود النموذج.
- حافظ على تشكيل النموذج خارج الشفرة المصدرة.

## التدريب

استخدام`code/main.py`للتحقق من مبدأ الطلب بدون الاتصال بمزود.
