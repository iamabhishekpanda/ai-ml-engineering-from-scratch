# شركة "آزور" للصيد

> تعامل التجارب والتقييمات والنسخة النموذجية والتنفيذ كطريق ترقية واحد يمكن تعقبه.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## أهداف التعلم

- تعريف تجربة، مجموعة بيانات، تشغيل، وترقية قرار.
- ضع أدلة التقييم مرفقة إلى النموذج أو النسخة المطلوبة.
- مقارنة عمليات التنفيذ المرشح مع بيانات الاختبار الثابتة.
- إمدادات التطوير والتنمية والإنتاج منفصلة.
- توقف الترقية عندما تفشل البوابة الجودة أو السلامة

## التدريب

استخدام`code/main.py`كل مرشح يحتاج إلى صاحب، مجموعة بيانات، عتبة، و هدف إعادة التدريب.
