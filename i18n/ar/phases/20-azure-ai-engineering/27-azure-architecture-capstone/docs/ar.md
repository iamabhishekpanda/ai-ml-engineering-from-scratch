# Azure AI Architecture Capstone

> الدفاع عن تصميم حلول الذكاء الاصطناعي الكامل مع أدلة على التنفيذ ودليل على التقييم ونموذج تشغيلي.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## أهداف التعلم

- إنتاج إطارات السياق والحاوية وتدفق البيانات ونشر.
- شرح تعادلات خدمة Azure والإطار.
- إثبات الهوية والأمن والتقييم والتحكم في إعادة التدريب.
- التكلفة الحالية، التأخير، الموثوقية، والجودة الميزانية.
- اكتب سجل قرارات الهندسة المعمارية للمراجعة.

## التدريب

استخدام`code/main.py`للتحقق من قائمة التحقق من الأدلة. لا يتواصل الفن الأثري مع Azure؛ فإنه يُحقق من استكمال التصميم قبل النشر.
