# عمليات أزور فورية

> تعامل الإشارات، وإعدادات النموذج، وقواعد السلامة، ونتائج التقييم كمدخلات الإنتاج المعدلة.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI, Azure AI Foundry
**Time:** ~60 minutes

## أهداف التعلم

- إشارات النسخة وبرامج النموذج معاً
- قم ببناء مجموعة بيانات تراجعية صغيرة قبل تغيير طلب.
- مقارنة الجودة، التأخير، الرفض، وتأثيرات التكلفة الرمزية.
- تطلب موافقة على تغييرات سريعة في الإنتاج.
- ضع بيانات التردد المعدنية إلى جانب كل إصدار.

## التدريب

استخدام`code/main.py`للتحقق من سجل الإصدار السريع. الإصدار يحتاج إلى مجموعة بيانات، وعتبة، والصاحب، والإصدار الاحتياطي.
