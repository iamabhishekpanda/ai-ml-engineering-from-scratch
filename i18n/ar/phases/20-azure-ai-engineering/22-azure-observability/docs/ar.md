# الملاحظة في Azure

> تحويل جودة النموذج وصحة النظام وتأثير المستخدم إلى إشارات يمكن للمشغل أن يتصرف بناء عليها.

**Type:** Build
**Languages:** Python
**Prerequisites:** Debugging & Profiling, Azure Container Apps
**Time:** ~60 minutes

## أهداف التعلم

- تمييز السجلات والمقاييس والسقوطات وسجلات التقييم.
- تحديد أرقام تعريف التواصل عبر API، الاستعراض، النموذج، والدعوات الأداة.
- حدد تحذيرات على تأخير، الأخطاء، التكلفة، والجودة التحرك.
- إزالة الأسرار والمحتوى الحساس من المراقبة
- اكتب خريطة إشارة الاستجابة للمحادثات

## التدريب

استخدام`code/main.py`للتحقق من مدى إمكانية التحقق من خطة قابلة للملاحظة. يعد العلامة مفيدًا فقط عندما تربط طلب المستخدم بقرار قابلة للقياس.
