# تطبيقات Azure Container

> حزمة API الذكاء الاصطناعي والعامل مع التحقق من الصحة، والإصلاحات، وإشارات التوسع، وطريق العودة.

**Type:** Build
**Languages:** Python
**Prerequisites:** Docker for AI, Azure Identity and Networking
**Time:** ~60 minutes

## أهداف التعلم

- إطار إدارة المعاملات المفصلة، العامل، وموظف الموعد المحدد.
- تحديد عمليات التحقق من الاستعداد والحياة.
- اختر إشارات التوسع لتحملات العمل على النموذج والحصول على النتائج.
- استخدم الإصلاحات لتنفيذ التحكم والعودة.
- ابقوا التكوين والسرات خارج الصورة

## التدريب

استخدام`code/main.py`للتحقق من إشعار نشر الحاويات. فإنه يفتقد أبحاث الصحة، استراتيجية مراجعة، وتكوين غير السري.
