# Fundamentos de Engenharia de IA do Azure

> Mapear uma carga de trabalho de IA para serviços do Azure, limites de implantação e restrições mensuráveis.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## Objetivos de aprendizagem

- Responsabilidades de modelo, dados, aplicação e plataforma separadas.
- Escolha os serviços do Azure entre as restrições de carga de trabalho.
- Defina a latência, a confiabilidade, a privacidade e os orçamentos de custos.
- Escreva um pequeno registro de decisão de arquitetura.
- Identificar as provas necessárias antes da implantação.

## Prática

Utilização`code/main.py`Para validar um plano de serviço, registar a carga de trabalho, limite de confiança, classe de dados, objetivo de implantação e sinal de retrocesso antes de selecionar um serviço.
