# Arquitetura de IA do Azure Capstone

> Defender um projeto completo de solução de IA com evidências de implantação, evidências de avaliação e um modelo operacional.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Objetivos de aprendizagem

- Produzir conteúdo, contêiner, fluxo de dados e visualizações de implantação.
- Explicar as compensações de serviços e de framework do Azure.
- Demonstrar identidade, segurança, avaliação e controles de retrocesso.
- Presente orçamento de custos, latência, confiabilidade e qualidade.
- Escreva um registro de decisão de arquitetura para revisão.

Utilização`code/main.py`O artefato não entra em contacto com o Azure; verifica que o projeto está completo antes da implantação.
