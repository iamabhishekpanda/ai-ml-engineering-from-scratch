# Fundição de IA Azure

> Tratar experimentos, avaliações, versões de modelos e implementações como um caminho de promoção rastreável.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## Objetivos de aprendizagem

- Defina um experimento, conjunto de dados, execução e decisão de promoção.
- Mantenha as provas de avaliação anexadas a um modelo ou a uma versão imediata.
- Compare as instalações de candidatos com dados de teste fixos.
- Desenvolvimento, estagização e recursos de produção separados.
- Parar a promoção quando um portal de qualidade ou segurança falhar.
