# Azure RAG Uygulama

> Depolama, arama, model erişim, güvenlik ve değerlendirmeyi tek bir dağıtılabilir geri alım sistemine birleştirin.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Öğrenme Hedefleri

- Yedikleri ve sorgu yollarını ayrı ayrı çizin.
- Kaynaktan cevaplara erişim filtrelerini koruyun.
- Yerleşme ve alıntı kontrollerini ekleyin.
- Bütçe geri alımı, model ve ağ gecikmesi.
- Geri dönüşü güvenli bir RAG hizmeti dağıtın.

## Pratik

Kullanım`code/main.py`RAG dağıtım planının doğrulanması için.
