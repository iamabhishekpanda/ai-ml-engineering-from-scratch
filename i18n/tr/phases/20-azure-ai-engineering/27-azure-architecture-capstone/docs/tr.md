# Azure AI Mimarlığı Capstone

> Deployment kanıtları, değerlendirme kanıtları ve bir işletim modeli ile tam bir AI çözüm tasarımı savunmak.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Öğrenme Hedefleri

- Konekst, konteyner, veri akışı ve dağıtım görüntüleri üretin.
- Azure hizmet ve çerçeve pazarlamalarını açıklayın.
- Kimlik, güvenlik, değerlendirme ve geri dönüş kontrollerini göster.
- Şu anki maliyet, gecikme, güvenilirlik ve kalite bütçeleri.
- Tekrar incelemek için mimari karar kaydı yazın.

## Pratik

Kullanım`code/main.py`Bu eser Azure ile temas kurmuyor, tasarının dağıtımdan önce tamamlandığını kontrol ediyor.
