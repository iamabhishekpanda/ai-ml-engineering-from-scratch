# Azure OpenAI

> Görev isimleri, kvotalar, tekrar denemeler, güvenlik ve değerlendirme kanıtları etrafında tasarım modeli erişim.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## Öğrenme Hedefleri

- Azure OpenAI kaynaklarını model dağıtım isimlerinden ayırın.
- Bütçe belirtileri, gecikme, geçiş ve başarısızlık tekrar denemeleri.
- Yapılandırılmış çıkışı uygulama koduna ulaşmadan önce doğrulayın.
- Modelle sınırlara içerik güvenliği ve reddetme işlemini ekleyin.
- Model yapılandırmasını kaynak kodu dışında tutun.

## Pratik

Kullanım`code/main.py`Bu, bir sunucuyu aramasız bir model istek planını onaylamak için kullanılır.
