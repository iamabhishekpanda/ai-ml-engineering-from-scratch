# Arquitectura de IA de Azure Capstone

> Defender un diseño completo de soluciones de IA con evidencia de implementación, evidencia de evaluación y un modelo operativo.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Objetivos de aprendizaje

- Produce vistas de contexto, contenedor, flujo de datos y implementación.
- Explicar las compensaciones de servicio y marco de Azure.
- Demostrar la identidad, la seguridad, la evaluación y los controles de retroceso.
- Presente presupuesto de costes, latencia, fiabilidad y calidad.
- Escriba un registro de la decisión de arquitectura para revisión.

## Práctica

Usar`code/main.py`El artefacto no se comunica con Azure; verifica que el diseño está completo antes de su implementación.
