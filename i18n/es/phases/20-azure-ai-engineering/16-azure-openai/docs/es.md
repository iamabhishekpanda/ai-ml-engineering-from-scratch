# Azure OpenAI

> El modelo de diseño de acceso en torno a nombres de despliegue, cuotas, retrasos, seguridad y pruebas de evaluación.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Separar los recursos de Azure OpenAI de los nombres de implementación de modelos.
- Tokens de presupuesto, latencia, rendimiento y retrasos de fallas.
- Valida la salida estructurada antes de que llegue al código de aplicación.
- Añadir seguridad del contenido y manejo de la negativa a un límite del modelo.
- Mantenga la configuración del modelo fuera del código fuente.

## Práctica

Usar`code/main.py`El artefacto es intencionalmente fuera de línea y determinista.
