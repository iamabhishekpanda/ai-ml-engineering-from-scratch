# Observabilidad de Azure

> Convierta la calidad del modelo, la salud del sistema y el impacto del usuario en señales que un operador puede actuar.

**Type:** Build
**Languages:** Python
**Prerequisites:** Debugging & Profiling, Azure Container Apps
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Distinguir registros, métricas, rastros y registros de evaluación.
- Definir las identidades de correlación en API, recuperación, modelo y llamadas de herramientas.
- Establezca alertas sobre latencia, errores, costo y calidad.
- Eliminar secretos y contenido sensible de la telemetría.
- Escriba un mapa de señal de respuesta al incidente.

## Práctica

Usar`code/main.py`El rastro es útil sólo cuando conecta una solicitud de usuario a una decisión medible.
