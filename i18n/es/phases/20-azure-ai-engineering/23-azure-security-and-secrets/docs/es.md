# Seguridad y secretos de Azure

> Proteger las identidades, las instrucciones, los documentos y las salidas de modelos a través de los límites del sistema completo de IA.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Clasifique la sensibilidad de la respuesta, el documento, la incorporación y la salida.
- Almacenar secretos en la bóveda clave y acceder a ellos a través de la identidad gestionada.
- Aplicar el menor privilegio a los recursos de datos y modelos.
- Prueba de inyección rápida, exfiltración de datos y uso inseguro de herramientas.
- Definir pruebas de auditoría y rotación.

## Práctica

Usar`code/main.py`Rechaza los secretos de texto claro y la propiedad faltante de las vías de datos sensibles.
