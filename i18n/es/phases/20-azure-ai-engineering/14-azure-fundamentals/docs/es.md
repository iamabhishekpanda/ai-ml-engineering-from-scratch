# Fundamentos de la ingeniería de IA de Azure

> Mapa de una carga de trabajo de IA a los servicios de Azure, límites de implementación y restricciones medibles.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Responsabilidades de modelo, datos, aplicación y plataforma separadas.
- Seleccione los servicios de Azure entre las restricciones de carga de trabajo.
- Definir la latencia, la fiabilidad, la privacidad y los presupuestos de costos.
- Escriba un pequeño registro de decisiones de arquitectura.
- Identifique las pruebas requeridas antes del despliegue.

## Práctica

Usar`code/main.py`registrar la carga de trabajo, el límite de confianza, la clase de datos, el objetivo de implementación y la señal de retroceso antes de seleccionar un servicio.
