# Contratos de almacenamiento y datos de Azure

> Mantenga los documentos, metadatos, incorporaciones y reglas del ciclo de vida alineados en un plano de datos de IA.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Clasificar los datos de origen antes de almacenarlos o indexarlos.
- Definir manchas, metadatos y contratos de eliminación.
- Diseñar una ingestión idempotente y comportamiento de repetición.
- Separar los datos crudos, procesados y de evaluación.
- Verificar las pruebas de retención y eliminación.

## Práctica

Usar`code/main.py`Verifica los campos de metadatos, retención y reproducción requeridos sin requerir una cuenta de Azure.
