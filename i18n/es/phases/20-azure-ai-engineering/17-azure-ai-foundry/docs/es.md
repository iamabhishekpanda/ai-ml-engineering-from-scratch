# Fundería de IA de Azure

> Trate los experimentos, evaluaciones, versiones de modelos y implementaciones como una vía de promoción rastreable.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## Objetivos de aprendizaje

- Definir un experimento, conjunto de datos, ejecución y decisión de promoción.
- Mantenga la evidencia de evaluación adjunta a un modelo o a una versión rápida.
- Comparar los despliegues de candidatos con los datos de ensayos fijos.
- Recursos de desarrollo, puesta en escena y producción separados.
- Dejar de promocionar cuando una puerta de calidad o seguridad falla.

## Práctica

Usar`code/main.py`Cada candidato necesita un propietario, un conjunto de datos, un umbral y un objetivo de retroceso.
