# Despliegue de Azure RAG

> Unir almacenamiento, búsqueda, acceso a modelos, seguridad y evaluación en un sistema de recuperación desplegable.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Objetivos de aprendizaje

- Dibujar las vías de ingestión y consulta por separado.
- Preserva los filtros de acceso desde la fuente hasta la respuesta.
- Añadir controles de base y citación.
- Recuperación de presupuesto, modelo y latencia de red.
- Despliegue un servicio RAG seguro para el retroceso.

## Práctica

Usar`code/main.py`para validar un plan de despliegue de RAG. verifica las etapas de ingestión, recuperación, generación, citación y retroceso.
