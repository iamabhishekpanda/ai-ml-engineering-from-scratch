# Azure शीघ्र संचालन

> प्रम्प्ट, मॉडल सेटिंग्स, सुरक्षा नियम और मूल्यांकन परिणामों को संस्करणित उत्पादन इनपुट के रूप में व्यवहार करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI, Azure AI Foundry
**Time:** ~60 minutes

## सीखने के लक्ष्य

- संस्करण संकेत और मॉडल पैरामीटर एक साथ।
- एक प्रॉम्प्ट बदलने से पहले एक छोटा रिग्रेशन डेटासेट बनाएं।
- गुणवत्ता, विलंबता, अस्वीकार और टोकन लागत प्रभावों की तुलना करें।
- उत्पादन में शीघ्र परिवर्तन के लिए अनुमोदन की आवश्यकता होगी।
- प्रत्येक रिलीज़ के साथ रूलबैक मेटाडेटा रखें।

## अभ्यास

उपयोग करें`code/main.py`एक रिलीज के लिए एक डेटासेट, सीमा, मालिक और रूलबैक संस्करण की आवश्यकता होती है।
