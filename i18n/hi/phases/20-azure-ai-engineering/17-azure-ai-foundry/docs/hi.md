# Azure AI फ्यूंडरी

> प्रयोगों, मूल्यांकन, मॉडल संस्करणों और तैनाती को एक ट्रैक करने योग्य प्रचार पथ के रूप में देखें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## सीखने के लक्ष्य

- प्रयोग, डेटासेट, रन और पदोन्नति निर्णय को परिभाषित करें।
- मूल्यांकन के साक्ष्य को मॉडल या शीघ्र संस्करण से जोड़ा रखें।
- उम्मीदवारों की तैनाती की तुलना फिक्स्ड टेस्ट डेटा से करें।
- विकास, चरणबद्धता और उत्पादन संसाधनों को अलग करना।
- गुणवत्ता या सुरक्षा गेट विफल होने पर पदोन्नति बंद करें।

## अभ्यास

उपयोग करें`code/main.py`प्रत्येक उम्मीदवार को एक मालिक, डेटासेट, सीमा और रोलबैक लक्ष्य की आवश्यकता होती है।
