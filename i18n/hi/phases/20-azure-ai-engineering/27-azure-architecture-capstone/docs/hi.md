# Azure AI आर्किटेक्चर कैपस्टोन

> तैनाती के सबूतों, मूल्यांकन के सबूतों और एक ऑपरेटिंग मॉडल के साथ एक पूर्ण एआई समाधान डिजाइन का बचाव करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## सीखने के लक्ष्य

- संदर्भ, कंटेनर, डेटा प्रवाह और तैनाती दृश्य उत्पन्न करें।
- Azure सेवा और फ्रेमवर्क ट्रेडऑफ की व्याख्या करें।
- पहचान, सुरक्षा, मूल्यांकन और रोलबैक नियंत्रण का प्रदर्शन करें।
- वर्तमान लागत, विलंबता, विश्वसनीयता और गुणवत्ता बजट।
- समीक्षा के लिए वास्तुकला निर्णय रिकॉर्ड लिखें।

## अभ्यास

उपयोग करें`code/main.py`कैपस्टोन सबूत चेकलिस्ट को मान्य करने के लिए। कलाकृतियों से संपर्क नहीं होता है Azure; यह जांचता है कि डिजाइन तैनाती से पहले पूरा हो गया है।
