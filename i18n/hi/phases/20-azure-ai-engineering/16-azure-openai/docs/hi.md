# Azure OpenAI

> तैनाती के नाम, कोटा, पुनः प्रयास, सुरक्षा और मूल्यांकन के प्रमाण के आसपास डिजाइन मॉडल पहुंच।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## सीखने के लक्ष्य

- Azure OpenAI संसाधनों को मॉडल तैनाती नामों से अलग करें।
- बजट टोकन, विलंबता, पारगमन, और विफलता पुनः प्रयासों।
- आवेदन कोड तक पहुंचने से पहले संरचित आउटपुट को मान्य करें।
- एक मॉडल सीमा में सामग्री सुरक्षा और अस्वीकरण संभाल जोड़ें।
- स्रोत कोड के बाहर मॉडल विन्यास रखें।

## अभ्यास

उपयोग करें`code/main.py`एक प्रदाता को कॉल किए बिना एक मॉडल अनुरोध योजना को मान्य करने के लिए। कलाकृतियां जानबूझकर ऑफ़लाइन और निर्धारक हैं।
