# Azure भंडारण और डेटा अनुबंध

> दस्तावेज़ों, मेटाडेटा, एम्बेडिंग और जीवन चक्र नियमों को एआई डेटा प्लेन में संरेखित रखें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## सीखने के लक्ष्य

- भंडारण या सूचकांकित करने से पहले स्रोत डेटा को वर्गीकृत करें।
- ब्लेब, मेटाडेटा और हटाने के अनुबंधों को परिभाषित करें।
- अक्षम सेवन और पुनः खेलने के व्यवहार को डिजाइन करें।
- कच्चे, प्रसंस्करण और मूल्यांकन डेटा को अलग करना।
- प्रतिधारण और हटाने के प्रमाण की जांच करें।

## अभ्यास

उपयोग करें`code/main.py`यह एक Azure खाते की आवश्यकता के बिना आवश्यक मेटाडेटा, भंडारण और पुनःप्ले फ़ील्ड की जांच करता है।
