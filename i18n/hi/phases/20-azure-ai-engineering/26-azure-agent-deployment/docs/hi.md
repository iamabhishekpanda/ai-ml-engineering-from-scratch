# Azure एजेंट तैनाती

> स्पष्ट स्थिति, अनुमति, अनुमोदन, समय-आउट और पुनर्प्राप्ति पथ के साथ उपकरण-उपयोग एजेंटों को तैनात करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Functions for AI Workloads, Azure Security and Secrets
**Time:** ~75 minutes

## सीखने के लक्ष्य

- एक एजेंट को सीमित संक्रमणों के साथ एक राज्य मशीन के रूप में मॉडल करें।
- प्रत्येक कार्य और उपयोगकर्ता संदर्भ के अनुसार उपकरण अनुमतियां लागू करें।
- अपरिवर्तनीय कार्यों के लिए अनुमोदन गेट जोड़ें।
- समय-समय पर, दोहरी घटनाओं और आंशिक उपकरण विफलता से पुनर्प्राप्त करें।
- संवेदनशील उपयोगिताओं को संग्रहीत किए बिना प्रत्येक निर्णय का पता लगाएं।

## अभ्यास

उपयोग करें`code/main.py`प्रत्येक उपकरण किनारे अनुमति, समय सीमा, पुनः प्रयास, और ऑडिट व्यवहार की आवश्यकता है।
