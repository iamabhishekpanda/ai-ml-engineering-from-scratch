# Azure AI इंजीनियरिंग मूल बातें

> Azure सेवाओं, तैनाती सीमाओं और मापने योग्य प्रतिबंधों के लिए AI कार्यभार का नक्शा बनाएं।

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## सीखने के लक्ष्य

- अलग मॉडल, डेटा, एप्लिकेशन और प्लेटफॉर्म जिम्मेदारियां।
- कार्यभार प्रतिबंधों में से Azure सेवाओं का चयन करें।
- विलंबता, विश्वसनीयता, गोपनीयता और लागत बजट को परिभाषित करें।
- एक छोटी वास्तुकला निर्णय रिकॉर्ड लिखें।
- तैनाती से पहले आवश्यक साक्ष्य की पहचान करें।

## अभ्यास

उपयोग करें`code/main.py`सेवा योजना को मान्य करने के लिए। किसी सेवा का चयन करने से पहले कार्यभार, विश्वास सीमा, डेटा वर्ग, तैनाती लक्ष्य और रूलबैक संकेत रिकॉर्ड करें।
