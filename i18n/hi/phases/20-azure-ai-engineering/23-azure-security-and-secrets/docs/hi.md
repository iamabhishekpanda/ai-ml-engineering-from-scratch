# Azure सुरक्षा और रहस्य

> पूर्ण एआई प्रणाली सीमाओं के पार पहचान, संकेत, दस्तावेज और मॉडल आउटपुट की रक्षा करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## सीखने के लक्ष्य

- शीघ्र, दस्तावेज, एम्बेडिंग और आउटपुट संवेदनशीलता को वर्गीकृत करें।
- कुंजी वॉल्ट में रहस्यों को स्टोर करें और प्रबंधित पहचान के माध्यम से उन तक पहुंचें।
- डेटा और मॉडल संसाधनों पर न्यूनतम विशेषाधिकार लागू करें।
- शीघ्र इंजेक्शन, डेटा निष्कर्षण और असुरक्षित उपकरण का प्रयोग करने का परीक्षण करें।
- लेखा परीक्षा और रोटेशन के प्रमाण को परिभाषित करें।

## अभ्यास

उपयोग करें`code/main.py`यह स्पष्ट पाठ रहस्य और संवेदनशील डेटा पथ के लिए अनुपलब्ध स्वामित्व को अस्वीकार करता है।
