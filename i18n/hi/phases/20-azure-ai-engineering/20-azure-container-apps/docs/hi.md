# Azure कंटेनर ऐप्स

> स्वास्थ्य जांच, संशोधन, स्केलिंग संकेतों और एक रोलबैक पथ के साथ एक एआई एपीआई और कार्यकर्ता पैकेज करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Docker for AI, Azure Identity and Networking
**Time:** ~60 minutes

## सीखने के लक्ष्य

- अलग एपीआई, कार्यकर्ता, और नियोजित नौकरी कंटेनर।
- तैयारता और जीवन की जाँच को परिभाषित करें।
- मॉडल और पुनर्प्राप्ति कार्यभार के लिए स्केलिंग संकेत चुनें।
- नियंत्रण रोलआउट और रोलआउट के लिए संशोधनों का उपयोग करें।
- छवि के बाहर कॉन्फ़िगरेशन और रहस्य रखें।

## अभ्यास

उपयोग करें`code/main.py`यह स्वास्थ्य जांच, संशोधन रणनीति और गैर-गुप्त विन्यास की जांच करता है।
