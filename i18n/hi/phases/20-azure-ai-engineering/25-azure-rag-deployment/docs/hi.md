# Azure RAG तैनाती

> भंडारण, खोज, मॉडल एक्सेस, सुरक्षा और मूल्यांकन को एक तैनाती योग्य पुनर्प्राप्ति प्रणाली में जोड़ें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## सीखने के लक्ष्य

- सेवन और प्रश्न पथ को अलग से खींचें।
- स्रोत से उत्तर तक पहुँच फ़िल्टर को संरक्षित करें।
- जमीनीकरण और उद्धरण जाँच जोड़ें।
- बजट पुनर्प्राप्ति, मॉडल, और नेटवर्क विलंबता।
- एक रोल-बैक सुरक्षित RAG सेवा को तैनात करें।

## अभ्यास

उपयोग करें`code/main.py`आरएजी तैनाती योजना को मान्य करने के लिए। यह सेवन, निकासी, उत्पादन, उद्धरण और रोलबैक चरणों की जांच करता है।
