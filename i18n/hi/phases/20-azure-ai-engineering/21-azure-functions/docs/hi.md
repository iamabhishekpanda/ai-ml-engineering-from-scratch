# एआई वर्कलोड के लिए Azure फ़ंक्शन

> सीमित कार्यों, सेवन ट्रिगर और हल्के ऑर्केस्ट्रेशन के लिए घटना-चालित कार्यों का उपयोग करें।

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Container Apps, APIs & Keys
**Time:** ~60 minutes

## सीखने के लक्ष्य

- सीमित, घटना-चालित कार्य के लिए फ़ंक्शन चुनें।
- ट्रिगर, पुनः प्रयास, टाइमआउट और जहर संदेश व्यवहार को परिभाषित करें।
- हाइड्रेटरों को अशक्त और अवलोकन योग्य रखें।
- लंबे मॉडल कार्यों को एक छोटे अनुरोध पथ में रखने से बचें।
- एक कार्यकर्ता को एक टिकाऊ हस्तान्तरण डिजाइन करें।

## अभ्यास

उपयोग करें`code/main.py`यह निष्क्रियता, समय सीमा, पुनः प्रयास और मृत अक्षर निर्णयों की जांच करता है।
