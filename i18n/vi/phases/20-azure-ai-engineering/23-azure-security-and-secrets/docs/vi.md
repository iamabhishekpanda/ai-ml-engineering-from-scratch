# Azure Security và bí mật

> Bảo vệ danh tính, lời nhắc, tài liệu và các mô hình ra ngoài trên toàn bộ ranh giới hệ thống AI.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## Mục tiêu học tập

- Đánh phân loại nhạy cảm prompt, tài liệu, nhúng và đầu ra.
- Cung cấp bí mật trong Key Vault và truy cập thông qua danh tính được quản lý.
- Sử dụng quyền lợi tối thiểu cho các nguồn dữ liệu và mô hình.
- Kiểm tra tiêm nhanh chóng, khai thác dữ liệu và sử dụng công cụ không an toàn.
- Định nghĩa chứng cứ kiểm toán và quay.

## Thực hành

Sử dụng `code/main.py`Nó từ chối bí mật văn bản công khai và mất quyền sở hữu cho các con đường dữ liệu nhạy cảm.
