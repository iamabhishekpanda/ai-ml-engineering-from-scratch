# Azure AI Architecture Capstone

> Bảo vệ thiết kế giải pháp AI hoàn chỉnh với bằng chứng triển khai, bằng chứng đánh giá và mô hình hoạt động.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Mục tiêu học tập

- Tạo bối cảnh, container, lưu lượng dữ liệu và triển khai quan điểm.
- Giải thích các dịch vụ Azure và thương mại khung.
- Cụ thể xác định danh tính, an ninh, đánh giá và kiểm soát quay trở lại.
- Chi phí hiện tại, thời gian trễ, độ tin cậy và ngân sách chất lượng.
- Viết một hồ sơ quyết định kiến trúc để xem xét.

## Thực hành

Sử dụng `code/main.py`để xác nhận danh sách kiểm tra bằng chứng đáy cuối. Cấu vật không liên lạc với Azure; nó kiểm tra rằng thiết kế đã hoàn thành trước khi triển khai.
