# Azure OpenAI

> Thiết kế mô hình truy cập xung quanh tên triển khai, hạn ngạch, thử nghiệm lại, an toàn và chứng cứ đánh giá.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## Mục tiêu học tập

- Chia tách các nguồn tài nguyên Azure OpenAI từ tên triển khai mô hình.
- Các mã thông báo ngân sách, thời gian trễ, thông qua, và thất bại thử lại.
- Thiết lập kết quả kết cấu trước khi nó đạt đến mã ứng dụng.
- Thêm an toàn nội dung và xử lý từ chối vào ranh giới mô hình.
- Giữ cấu hình mô hình bên ngoài mã nguồn.

## Thực hành

Sử dụng `code/main.py`để xác nhận một kế hoạch yêu cầu mô hình mà không gọi cho một nhà cung cấp.
