# Việc triển khai Azure RAG

> Kết hợp lưu trữ, tìm kiếm, truy cập mô hình, bảo mật và đánh giá thành một hệ thống lấy lại có thể triển khai.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Mục tiêu học tập

- Hình vẽ các đường tiêu thụ và truy vấn riêng biệt.
- Bảo tồn bộ lọc truy cập từ nguồn đến câu trả lời.
- Thêm kiểm tra về sự thành công và trích dẫn.
- Khám phá ngân sách, mô hình và độ trễ mạng.
- Đưa ra một dịch vụ RAG an toàn.

## Thực hành

Sử dụng `code/main.py`để xác nhận kế hoạch triển khai RAG. Nó kiểm tra các giai đoạn hấp thụ, lấy lại, sản xuất, trích dẫn và quay lại.
