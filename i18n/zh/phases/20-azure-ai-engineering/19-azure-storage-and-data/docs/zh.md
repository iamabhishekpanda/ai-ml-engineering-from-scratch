# 亚洲存储和数据合同

> 保持文件,元数据,嵌入式和生命周期规则在AI数据平面上一致.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## 学习目标

- 在存储或索引之前,将源数据分类.
- 定义点,元数据和删除合约.
- 设计无力摄入和重播行为.
- 单独分离原材料,加工和评估数据.
- 检查保留和删除证据.

## 实践

使用`code/main.py`检查需要的元数据,存储和重播字段,而不需要Azure帐户.
