#  Azure 容器应用程序

> 包装一个人工智能API和工作者, 检查健康,修改,扩展信号,

**Type:** Build
**Languages:** Python
**Prerequisites:** Docker for AI, Azure Identity and Networking
**Time:** ~60 minutes

## 学习目标

- 单独的API,工人和计划工作集装箱.
- 定义准备和活力检查.
- 选择扩展信号用于模型和检索工作负载.
- 使用修改控制推出和反推出.
- 保持配置和秘密在图像之外.

## 实践

使用`code/main.py`检查健康探测器,修改策略和非秘密配置.
