#  Azure AI 搜索

> 在将其连接到生成器之前,建立一个可以解释,过和测量的检索.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals, Data Management
**Time:** ~60 minutes

## 学习目标

- 选择关键字,向量和混合检索的字段.
- 保存源标识和部分来源.
- 在排名之前,应使用租户和安全过器.
- 单独测量回忆,排名质量和地性.
- 拒绝答案,如果没有证据.

## 实践

使用`code/main.py`为了验证索引合同,合同需要一个源代码,内容字段,嵌入字段和访问过器.
