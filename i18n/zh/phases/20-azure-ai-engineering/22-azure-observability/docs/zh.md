#  Azure 观察性

> 转化模型质量,系统健康和用户影响为操作员可以采取行动的信号.

**Type:** Build
**Languages:** Python
**Prerequisites:** Debugging & Profiling, Azure Container Apps
**Time:** ~60 minutes

## 学习目标

- 区分日志,指标,痕迹和评估记录.
- 定义 API,检索,模型和工具通话中的相关性ID.
- 设置延迟,错误,成本和质量漂移的警报.
- 删除隐私和敏感内容.
- 写一个事件响应信号地图.

## 实践

使用`code/main.py`测量可观性计划的验证. 痕迹只有在用户请求与可测量决策联系时才有用.
