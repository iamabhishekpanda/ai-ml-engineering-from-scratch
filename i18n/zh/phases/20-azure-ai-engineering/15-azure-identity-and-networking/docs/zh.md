#  Azure身份和网络

> 在部署前,使身份,网络界限和服务到服务访问明确.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals
**Time:** ~60 minutes

## 学习目标

- 区分人类身份,工作负载身份和资源身份.
- 优先管理身份,而不是嵌入式凭证.
- 描述私人终点,入境,出境以及最少的特权.
- 审查部署计划,以查询秘密和网络泄露.
- 试试一个"默认拒绝"政策.

## 实践

使用`code/main.py`处理每一次外部电话都是需要一个拥有者和一个审计信号的边界.
