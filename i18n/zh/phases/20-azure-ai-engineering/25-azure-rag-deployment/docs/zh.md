#  Azure RAG 部署

> 结合存储,搜索,模型访问,安全和评估,成为一个可部署的检索系统.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## 学习目标

- 单独绘制摄入和查询路径.
- 保存访问过器从源到答案.
- 增加了地和引用检查.
- 预算检索,模型和网络延迟.
- 部署一个安全的反弹性RAG服务.

## 实践

使用`code/main.py`核准RAG部署计划.它检查摄入,检索,生成,引用和反弹阶段.
