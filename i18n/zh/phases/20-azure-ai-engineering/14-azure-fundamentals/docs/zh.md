#  Azure AI 工程基础知识

> 映射人工智能工作负载到Azure服务,部署界限和可测量的限制.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## 学习目标

- 单独的模型,数据,应用和平台责任.
- 在工作负载限制中选择Azure服务.
- 定义延迟,可靠性,隐私和成本预算.
- 写一个建筑决定记录.
- 确定部署前所需的证据.

## 实践

使用`code/main.py`在选择服务之前记录工作负载,信任界限,数据类,部署目标和反转信号.
