#  Azure 安全和秘密

> 保护身份,提示,文件和模型输出,

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## 学习目标

- 分类提示,文件,嵌入和输出敏感性.
- 存储秘密在密钥库里,通过管理身份访问它们.
- 适用最小特权数据和模型资源.
- 试验即时注射,数据泄露,使用不安全的工具.
- 定义审计和轮换证据.

## 实践

使用`code/main.py`拒绝公开文本秘密和缺乏敏感数据路径的所有权.
