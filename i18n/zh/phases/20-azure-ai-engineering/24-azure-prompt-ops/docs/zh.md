#  Azure 快速操作

> 处理提示,模型设置,安全规则和评估结果作为版本生产输入.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI, Azure AI Foundry
**Time:** ~60 minutes

## 学习目标

- 版本提示和模型参数一起.
- 在改变提示之前,建立一个小回归数据集.
- 进行质量,延迟,拒绝和代币成本效应的比较.
- 要求批准生产的快速变化.
- 随着每次发布,随着随时发布的反弹转换元数据.

## 实践

使用`code/main.py`发布需要数据集,门,所有者和反弹版本.
