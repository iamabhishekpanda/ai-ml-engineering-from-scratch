#  Azure AI 架构 石头

> 捍卫一个完整的AI解决方案设计,包括部署证据,评估证据和运营模式.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## 学习目标

- 制作文本,容器,数据流和部署视图.
- 解释Azure服务和框架的折衷.
- 证明身份,安全,评估和反转控制.
- 现有成本,延迟,可靠性和质量预算.
- 写一个建筑决定记录,以便进行审查.

## 实践

使用`code/main.py`为了验证顶石证据检查清单.该文物不会与Azure联系,它在部署之前检查设计是否完整.
