# 对于AI工作负载的Azure功能

> 通过活动驱动的功能来完成有限的任务,摄入触发器和轻量级的调整.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Container Apps, APIs & Keys
**Time:** ~60 minutes

## 学习目标

- 选择为有限,以事件为主的工作的函数.
- 定义触发器,重新尝试,时间停止,和毒性信息行为.
- 让处理人员保持无力和可观察.
- 避免将长期的模型工作放在短途径中.
- 设计一个耐用的交给工人.

## 实践

使用`code/main.py`检查无效性,时间过期,重新尝试和死字母决策.
