# Les applications de conteneurs Azure

> Emballez une API d'IA et un travailleur avec des contrôles de santé, des révisions, des signaux d'échelle et un chemin de retour.

**Type:** Build
**Languages:** Python
**Prerequisites:** Docker for AI, Azure Identity and Networking
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Appareils d'API, de travail et de contenants de travail.
- Définir les contrôles de préparation et de vitalité.
- Choisissez les signaux d'échelle pour les charges de travail de modèle et de récupération.
- Utilisez des révisions pour le déploiement contrôlé et le retour.
- Gardez la configuration et les secrets hors de l'image.

## Pratique

Utilisation `code/main.py`Il vérifie les sondes de santé, la stratégie de révision et la configuration non secrète.
