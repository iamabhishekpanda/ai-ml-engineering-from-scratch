# Architecture de l'IA Azure Capstone

> Défendre une conception complète de solutions d'IA avec des preuves de déploiement, des preuves d'évaluation et un modèle d'exploitation.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## Objectifs d'apprentissage

- Produire des vues de contexte, de conteneur, de flux de données et de déploiement.
- Expliquer les compromis de service et de cadre Azure.
- Démontre l'identité, la sécurité, l'évaluation et les contrôles de retour.
- Les coûts, la latence, la fiabilité et la qualité actuels.
- Écrivez un dossier de décision architecturale à examiner.

## Pratique

Utilisation `code/main.py`L'artefact ne contacte pas Azure; il vérifie que la conception est complète avant le déploiement.
