# Azure OpenAI

> Accès à des modèles de conception autour des noms de déploiement, des quotas, des essais répétés, des preuves de sécurité et d'évaluation.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Séparer les ressources Azure OpenAI des noms de déploiement de modèle.
- Les jetons budgétaires, la latence, le débit et les tentatives de rééchec.
- Valider la sortie structurée avant qu'elle n'atteigne le code de l'application.
- Ajouter la sécurité du contenu et la gestion des refus à une limite du modèle.
- Gardez la configuration du modèle hors code source.

## Pratique

Utilisation `code/main.py`L'artéfact est intentionnellement hors ligne et déterministe.
