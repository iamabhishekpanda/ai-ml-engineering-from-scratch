# Fonderie d'IA Azure

> Traiter les expériences, les évaluations, les versions de modèles et les déploiements comme une voie de promotion traçable.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Définir une expérience, un ensemble de données, une décision de promotion et de mise en œuvre.
- Gardez les preuves d'évaluation attachées à un modèle ou à une version rapide.
- Comparer les déploiements de candidats avec les données de test fixes.
- Réservoir des ressources de développement, de mise en scène et de production.
- Arrêtez la promotion quand une porte de qualité ou de sécurité échoue.

## Pratique

Utilisation `code/main.py`Pour valider un dossier de promotion, chaque candidat a besoin d'un propriétaire, d'un ensemble de données, d'un seuil et d'un objectif de retour.
