# Fondements de l'ingénierie de l'IA Azure

> Mapez une charge de travail d'IA vers les services Azure, les limites de déploiement et les contraintes mesurables.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Responsabilités séparées de modèle, de données, d'application et de plateforme.
- Choisissez les services Azure parmi les contraintes de charge de travail.
- Définir la latence, la fiabilité, la confidentialité et les budgets de coûts.
- Écrivez un petit dossier de décision architecturale.
- Identifier les éléments de preuve requis avant le déploiement.

## Pratique

Utilisation `code/main.py`enregistrer la charge de travail, la limite de confiance, la classe de données, la cible de déploiement et le signal de retour avant de sélectionner un service.
