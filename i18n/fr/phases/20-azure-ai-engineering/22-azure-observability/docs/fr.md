# Observabilité en Azure

> Transformer la qualité du modèle, la santé du système et l'impact de l'utilisateur en signaux sur lesquels un opérateur peut agir.

**Type:** Build
**Languages:** Python
**Prerequisites:** Debugging & Profiling, Azure Container Apps
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Distinguer les journaux, les mesures, les traces et les dossiers d'évaluation.
- Définir les identifiants de corrélation à travers les appels API, récupération, modèle et outil.
- Définir des alertes sur la latence, les erreurs, le coût et la dérive de qualité.
- Retirez les secrets et les contenus sensibles de la télémétrie.
- Écrivez une carte de signal de réponse à l'incident.

## Pratique

Utilisation `code/main.py`Une trace n'est utile que lorsqu'elle relie une demande d'utilisateur à une décision mesurable.
