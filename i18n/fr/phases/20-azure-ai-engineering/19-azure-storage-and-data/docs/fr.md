# Contrats de stockage et de données Azure

> Gardez les documents, les métadonnées, les intégrations et les règles du cycle de vie alignés sur un plan de données d'IA.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## Objectifs d'apprentissage

- Classifier les données de source avant de les stocker ou de les indexer.
- Définir les contrats de blob, de métadonnées et de suppression.
- Conception d'ingestion et de répétition idempotent.
- Séparer les données brutes, traitées et d'évaluation.
- Vérifiez les preuves de conservation et de suppression.

## Pratique

Utilisation `code/main.py`Il vérifie les champs de métadonnées, de conservation et de lecture nécessaires sans avoir besoin d'un compte Azure.
