# Déploiement de RAG Azure

> Rejoignez le stockage, la recherche, l'accès au modèle, la sécurité et l'évaluation dans un système de récupération déployable.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Objectifs d'apprentissage

- Dessinez séparément les chemins d'ingestion et de requête.
- Conserver les filtres d'accès de la source à la réponse.
- Ajoutez des vérifications de fondation et de citation.
- Récupération budgétaire, modèle et latence réseau.
- Mettre en place un service RAG sans danger.

## Pratique

Utilisation `code/main.py`Il vérifie les étapes d'ingestion, de récupération, de génération, de citation et de retour.
