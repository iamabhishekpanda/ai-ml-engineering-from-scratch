# Contratos de armazenamento e dados do Azure

> Mantenha documentos, metadados, incorporações e regras do ciclo de vida alinhadas em um plano de dados de IA.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## Objetivos de aprendizagem

- Classificar os dados de origem antes de armazená-los ou indexá-los.
- Defina os contratos de manchas, metadados e eliminação.
- Desenhar ingestão idempotente e comportamento de repetição.
- Separar os dados brutos, processados e de avaliação.
- Verificar as provas de retenção e de exclusão.
