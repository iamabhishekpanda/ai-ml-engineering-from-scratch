# Implementação do Azure RAG

> Junte armazenamento, pesquisa, acesso a modelos, segurança e avaliação em um sistema de recuperação implementável.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## Objetivos de aprendizagem

- Desenhar os caminhos de ingestão e consulta separadamente.
- Preserva os filtros de acesso da fonte para a resposta.
- Adicionar verificação de base e citação.
- Recuperação de orçamento, modelo e latência da rede.
- Envolver um serviço RAG seguro para retrocesso.

## Prática

Utilização`code/main.py`Verifica as fases de ingestão, recuperação, geração, citação e retrocesso.
