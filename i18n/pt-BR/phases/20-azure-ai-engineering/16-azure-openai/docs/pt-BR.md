# Azure OpenAI

> Acesso a modelos de design em torno de nomes de implantação, cotas, retemptados, segurança e evidências de avaliação.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## Objetivos de aprendizagem

- Separar os recursos do Azure OpenAI dos nomes de implantação de modelos.
- Tokens de orçamento, latência, rendimento e tentativas de falha.
- Validar a saída estruturada antes de atingir o código de aplicação.
- Adicionar segurança do conteúdo e tratamento de recusa a um limite do modelo.
- Mantenha a configuração do modelo fora do código-fonte.
