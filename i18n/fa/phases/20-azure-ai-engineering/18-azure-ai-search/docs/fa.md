# جستجوی هوش مصنوعی Azure

> قبل از اتصال به نسل، بازیافت را بسازید که قابل توضیح، فیلتر و اندازه گیری باشد.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals, Data Management
**Time:** ~60 minutes

## اهداف یادگیری

- برای جستجوی کلمات کلیدی، ویکتور و هیبرید، زمینه هایی را انتخاب کنید.
- شناسایی منبع و محل اصلیت قطعه ها را حفظ کنید.
- قبل از رتبه بندی، فیلترهای کرایه و امنیتی را اعمال کنید.
- به طور جداگانه یادآوری، کیفیت رتبه بندی و زمینگیری را اندازه گیری کنید.
- جواب رو رد کن وقتي شواهد از دست رفته باشه

## تمرین

استفاده کنید`code/main.py`برای اعتبار قرارداد شاخص، قرارداد نیاز به یک شناسه منبع، زمینه محتوا، زمینه گنجانده و فیلتر دسترسی دارد.
