# اصول مهندسی هوش مصنوعی Azure

> یک بار کار هوش مصنوعی را به خدمات Azure، مرزهای پیاده سازی و محدودیت های قابل اندازه گیری نقشه برداری کنید.

**Type:** Learn
**Languages:** Python
**Prerequisites:** GPU Setup & Cloud, APIs & Keys
**Time:** ~60 minutes

## اهداف یادگیری

- مسئولیت های جداگانه مدل، داده، برنامه و پلتفرم.
- خدمات Azure را از محدوده های بار کاری انتخاب کنید.
- تعريف تاخیر، قابلیت اطمینان، حریم خصوصی و بودجه هزینه.
- یک پرونده تصمیم گیری معماری کوچک بنویسید.
- شواهد مورد نیاز قبل از ارسال را شناسایی کنید.

## تمرین

استفاده کنید`code/main.py`برای تأیید یک برنامه سرویس، بار کاری، مرز اعتماد، کلاس داده، هدف انتشار و سیگنال برگشت را قبل از انتخاب یک سرویس ثبت کنید.
