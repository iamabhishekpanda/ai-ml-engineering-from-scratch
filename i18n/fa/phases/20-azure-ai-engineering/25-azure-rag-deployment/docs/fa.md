# استفاده از Azure RAG

> ذخیره سازی، جستجو، دسترسی به مدل، امنیت و ارزیابی را در یک سیستم بازیافت قابل استفاده ترکیب کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Search, Azure Storage and Data, Azure OpenAI
**Time:** ~75 minutes

## اهداف یادگیری

- مسیرهای مصرف و جستجو را جداگانه بکشید.
- فیلترهای دسترسی را از منبع تا پاسخ نگه دارید.
- اضافه کردن چک های زمین و نقل قول
- بازیافت بودجه، مدل و تاخیر شبکه
- یک سرویس RAG امن را به صورت بازگردانده در اختیار قرار دهید.

## تمرین

استفاده کنید`code/main.py`برای تأیید یک برنامه پیاده سازی RAG. این برنامه مراحل مصرف، بازیافت، تولید، نقل و نقل و بازگشت را بررسی می کند.
