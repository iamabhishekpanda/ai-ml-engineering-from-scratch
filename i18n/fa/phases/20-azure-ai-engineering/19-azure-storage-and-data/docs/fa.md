# قرارداد های ذخیره سازی و داده های Azure

> اسناد، متاداتا، گنجانده شدن و قوانین چرخه زندگی را در یک سطح داده های هوش مصنوعی هماهنگ نگه دارید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Data Management, Azure AI Search
**Time:** ~60 minutes

## اهداف یادگیری

- قبل از ذخیره یا فهرست گذاری، داده های منبع را طبقه بندی کنید.
- قراردادهای بلب، متاداتا و حذف را تعریف کنید.
- طراحی ادرار بی قدرت و رفتار بازخورد
- داده های خام، پردازش شده و ارزیابی را جدا کنید.
- بررسی شواهد حفظ و حذف

## تمرین

استفاده کنید`code/main.py`برای تأیید قرارداد ذخیره سازی. این فیلدهای مورد نیاز متادتا، ذخیره سازی و بازیابی را بدون نیاز به حساب Azure بررسی می کند.
