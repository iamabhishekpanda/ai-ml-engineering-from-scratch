# آشور AI Foundry

> آزمایش ها، ارزیابی ها، نسخه های مدل ها و انتشارها را به عنوان یک مسیر تبلیغاتی قابل ردیابی در نظر بگیرید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI
**Time:** ~60 minutes

## اهداف یادگیری

- یک آزمایش، مجموعه داده ها، اجرا و تصمیمات ارتقاء را تعریف کنید.
- شواهد ارزیابی را به یک مدل یا نسخه سریع متصل کنید.
- مقایسه ی انتشار کاندیداها با داده های ثابت آزمایش
- منابع توسعه، مرحله بندی و تولید را جداگانه.
- وقتي يه دروازه کيفيتي يا امنيتي شکست خورده، ارتقاء رو متوقف کن

## تمرین

استفاده کنید`code/main.py`برای اعتبار دادن به یک سوابق ارتقاء هر نامزد به یک مالک، مجموعه داده، حد و هدف بازگشت نیاز دارد.
