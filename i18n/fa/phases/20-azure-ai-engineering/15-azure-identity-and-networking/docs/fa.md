# هویت Azure و شبکه سازی

> هویت، مرز های شبکه و دسترسی سرویس به سرویس را قبل از انتشار صریح کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure AI Engineering Fundamentals
**Time:** ~60 minutes

## اهداف یادگیری

- هویت انسانی، هویت بار کاری و هویت منابع را تشخیص دهید.
- هویت مدیریت شده را به جای اعتبارات داخلی ترجیح می دهد.
- نقاط انتهای خصوصی، ورود، خروج و کمترین امتیاز را شرح دهید.
- برنامه تحويل براي نفوذي هاي سري و شبکه رو بازنگري کن
- يه سيستم انکار به صورت پيش فرض رو امتحان کن

## تمرین

استفاده کنید`code/main.py`هر تماس خارجی را به عنوان یک مرز که نیاز به یک مالک و یک سیگنال حسابرسی دارد، رفتار کنید.
