# مشاهده ای از Azure

> کیفیت مدل، سلامت سیستم و تاثیر کاربر را به سیگنال هایی تبدیل کنید که یک اپراتور می تواند بر روی آن عمل کند.

**Type:** Build
**Languages:** Python
**Prerequisites:** Debugging & Profiling, Azure Container Apps
**Time:** ~60 minutes

## اهداف یادگیری

- تشخیص سوابق، متریک، ردیابی و سوابق ارزیابی
- شناسایی ارتباط را در API، بازیافت، مدل و تماس های ابزار تعریف کنید.
- هشدارها را در مورد تاخیر، خطا، هزینه و کیفیت تنظیم کنید.
- از تلمترئيم رازها و محتويات حساس را حذف کنيد.
- نقشه اي از واکنش به حادثه ها بنویسيد

## تمرین

استفاده کنید`code/main.py`برای تأیید یک برنامه مشاهده ای. یک ردیابی تنها زمانی مفید است که یک درخواست کاربر را به یک تصمیم قابل اندازه گیری متصل کند.
