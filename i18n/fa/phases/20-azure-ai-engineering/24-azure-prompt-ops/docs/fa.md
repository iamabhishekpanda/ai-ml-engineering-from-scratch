# عملیات فوری Azure

> به عنوان ورژن ورودی تولید، دستورات، تنظیمات مدل، قوانین ایمنی و نتایج ارزیابی را در نظر بگیرید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure OpenAI, Azure AI Foundry
**Time:** ~60 minutes

## اهداف یادگیری

- درخواست های نسخه و پارامترهای مدل با هم
- قبل از تغییر یک پیامک، یک مجموعه داده کوچک بازگشت را بسازید.
- با کیفیت، تاخیر، رد و تاثیرات هزینه توکن مقایسه کنید.
- برای تغییرات سریع تولید، درخواست تایید کنید.
- متاداتاای بازتاب را در کنار هر انتشار نگه دارید.

## تمرین

استفاده کنید`code/main.py`برای تأیید یک رکورد انتشار فوری. یک انتشار نیاز به مجموعه داده، حد، مالک و نسخه برگشت دارد.
