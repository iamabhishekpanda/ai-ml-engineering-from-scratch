# استفاده از آژانس Azure

> اجنتی که از ابزار استفاده می کنند را با حالت صریح، مجوزها، تأییدیه ها، زمان بندی ها و مسیرهای بازیابی استفاده کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Functions for AI Workloads, Azure Security and Secrets
**Time:** ~75 minutes

## اهداف یادگیری

- یک عامل را به عنوان یک ماشین دولتی با انتقال محدود مدل کنید.
- مجوزهای ابزار را در هر کار و زمینه کاربر اعمال کنید.
- دروازه های تایید برای اقدامات برگشت ناپذیر اضافه کنید.
- از زمان بندی ها، رویدادهای تکراری و شکست جزئی ابزار بهبود می یابد.
- بدون ذخیره کردن بار های حساس هر تصمیم رو ردیابی کنید.

## تمرین

استفاده کنید`code/main.py`براي اعتبار دادن نقشه ي نشين شدن مامور هر ابزار نياز به اجازه، زمانبندي، دوباره تلاش و رفتار حسابرسي دارد
