# برنامه های کنتینر Azure

> یک API هوش مصنوعی و کارگر را با چک های بهداشتی، اصلاحات، سیگنال های مقیاس بندی و مسیر برگشت بسته بندی کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Docker for AI, Azure Identity and Networking
**Time:** ~60 minutes

## اهداف یادگیری

- API، کارکن و کانتینر های کاری برنامه ریزی شده را جدا کنید.
- چک های آماده و زنده بودن را تعریف کنید.
- برای مدل و بار کاری بازیافت سیگنال های مقیاس را انتخاب کنید.
- برای کنترل بازتاب و بازتاب استفاده کنید.
- تنظیمات و رازها رو خارج از تصویر نگه دار

## تمرین

استفاده کنید`code/main.py`برای تأیید یک مانیست انتشار کانتینر. این بررسی تحقیقات بهداشتی، استراتژی تجدید نظر و پیکربندی غیر مخفی است.
