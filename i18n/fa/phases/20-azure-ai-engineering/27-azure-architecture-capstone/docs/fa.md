# معماری هوش مصنوعی Azure Capstone

> از یک طراحی کامل راه حل هوش مصنوعی با شواهد پیاده سازی، شواهد ارزیابی و یک مدل عملیاتی دفاع کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure RAG Deployment, Azure Agent Deployment, Azure Observability
**Time:** ~120 minutes

## اهداف یادگیری

- نمایش های زمینه، کانتینر، جریان داده ها و انتشار را تولید کنید.
- تعادلات خدمات و چارچوب Azure را توضیح دهید.
- هویت، امنیت، ارزیابی و کنترل برگشت را نشان دهید.
- هزینه، تاخیر، قابلیت اطمینان و بودجه کیفیت فعلی.
- یک پرونده تصمیم معماری برای بررسی بنویسید.

## تمرین

استفاده کنید`code/main.py`برای تأیید لیست چک شواهد سنگ اصلی. این اثر با Azure تماس نمی گیرد؛ قبل از انتشار، بررسی می کند که طراحی کامل است.
