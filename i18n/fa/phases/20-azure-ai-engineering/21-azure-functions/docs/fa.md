# عملکردهای Azure برای AI Workloads

> از عملکردهای مبتنی بر رویداد برای وظایف محدود، محرک های مصرف و آرکیسترینگ سبک استفاده کنید.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Container Apps, APIs & Keys
**Time:** ~60 minutes

## اهداف یادگیری

- برای کار محدود و مبتنی بر رویداد، تابع ها را انتخاب کنید.
- تعريف رفتار تيرگير، دوباره تلاش، زمان توقف و پيام زهر
- نگه داشتن بازداشت کنندگان بی اختیار و قابل مشاهده
- از قرار دادن کارهای طولانی در مسیر کوتاه درخواست اجتناب کنید.
- طراحی یک تحویل پایدار به یک کارگر.

## تمرین

استفاده کنید`code/main.py`برای تایید یک برنامه فعال کردن تابع. این بررسی می کند بی اختیار، زمان بندی، دوباره تلاش، و حرف های مرده تصمیمات.
