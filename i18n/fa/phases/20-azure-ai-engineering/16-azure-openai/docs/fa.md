# Azure OpenAI

> دسترسی به مدل طراحی در اطراف نام های انتشار، کوتا، آزمایشات مجدد، ایمنی و شواهد ارزیابی.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking
**Time:** ~60 minutes

## اهداف یادگیری

- منابع Azure OpenAI را از نام های انتشار مدل جدا کنید.
- توکن های بودجه، تاخیر، تولید و تلاش های شکست دوباره.
- قبل از رسیدن به کد برنامه، خروجی ساختار یافته را تأیید کنید.
- ایمنی محتوا و مدیریت انکار را به یک مرز مدل اضافه کنید.
- پیکربندی مدل را خارج از کد منبع نگه دارید.

## تمرین

استفاده کنید`code/main.py`بدون تماس با ارائه دهنده، برای تأیید یک طرح درخواست مدل. این آرتیفاکت عمداً غیر فعال و تعیین کننده است.
