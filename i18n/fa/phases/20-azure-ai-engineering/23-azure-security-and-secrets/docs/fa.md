# امنیت و راز های Azure

> محافظت از هویت ها، پیام ها، اسناد و مدل های تولید در سراسر مرز سیستم هوش مصنوعی.

**Type:** Build
**Languages:** Python
**Prerequisites:** Azure Identity and Networking, Azure Storage and Data
**Time:** ~60 minutes

## اهداف یادگیری

- حساسیت پرامپ، سند، ادغام و خروجی را طبقه بندی کنید.
- اسرار رو در کليز خزانه نگه دار و از طریق هویت مدیریت شده بهشون دسترسی داشته باش
- حداقل امتیاز را به منابع داده و مدل اعمال کنید.
- تزریق سریع، تخلیه داده ها و استفاده از ابزار غیر امن را امتحان کنید.
- تعریف شواهد بازرسی و گردش

## تمرین

استفاده کنید`code/main.py`این برنامه، راز های متن ساده و مالکیت گمشده ی مسیرهای حساس داده ها را رد می کند.
